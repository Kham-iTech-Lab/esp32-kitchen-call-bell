# ESP32 กริ่งเรียกจากครัวไปหน้าร้าน

โค้ดประกอบคลิปของ **K iTech Review** (TikTok) / **Kham iTech Lab** (YouTube · Facebook)

กดปุ่มในครัว ให้กริ่งไปดังที่หน้าร้าน ESP32 สองตัวคุยกันตรง ๆ ผ่าน **ESP-NOW** ไม่ต้องใช้เราเตอร์ เน็ตล่มก็ยังใช้ได้ หน้าร้านกดรับทราบแล้ว ไฟในครัวจะติดบอกว่ามีคนเห็นแล้ว

## ของที่ต้องใช้

- บอร์ด ESP32 (DevKit V1) 2 ตัว
- ปุ่มกด 2 ตัว (ในครัว 1 ตัว หน้าร้านใช้เป็นปุ่มรับทราบ 1 ตัว)
- บัซเซอร์แบบแอคทีฟ (Active buzzer) 1 ตัว
- LED กับตัวต้านทาน 220Ω อย่างละ 1 ตัว
- อะแดปเตอร์มือถือ 5V พร้อมสาย USB 2 ชุด

## ต่อวงจร

**ตัวในครัว** (`kitchen_button`)

| อุปกรณ์ | ESP32 |
| --- | --- |
| ปุ่มกด | GPIO 13 กับ GND |
| LED สถานะ | GPIO 2 (ใช้ LED บนบอร์ดได้เลย) |

**ตัวหน้าร้าน** (`front_bell`)

| อุปกรณ์ | ESP32 |
| --- | --- |
| บัซเซอร์ (+) | GPIO 25 |
| บัซเซอร์ (−) | GND |
| LED | GPIO 26 → 220Ω → LED → GND |
| ปุ่มรับทราบ | GPIO 27 กับ GND |

ทั้งสองตัวใช้ไฟ 5V จากอะแดปเตอร์มือถือ ไม่ต้องยุ่งกับไฟบ้าน

## ติดตั้ง

1. ใน Arduino IDE ลงบอร์ด **esp32 by Espressif** ใช้ได้ทั้งรุ่น 2.x และ 3.x ไม่ต้องลงไลบรารีเพิ่ม
2. อัปโหลด `kitchen_button.ino` ลงตัวในครัว และ `front_bell.ino` ลงตัวหน้าร้าน
3. เปลี่ยน `GROUP_ID` ในทั้งสองไฟล์ให้เป็นเลขของร้านคุณเอง ใช้เลขเดียวกันทั้งสองไฟล์ จะได้ไม่ไปชนกับร้านข้าง ๆ ที่ใช้โค้ดเดียวกัน
4. ลองกดปุ่มในครัว หน้าร้านจะดังปี๊บ 3 ครั้ง แล้วดังเตือนซ้ำทุก 15 วินาทีจนกว่าจะมีคนกดรับทราบ

## ไฟในครัวบอกอะไร

| ไฟ | ความหมาย |
| --- | --- |
| กระพริบเร็ว | กำลังส่ง |
| กระพริบช้า | หน้าร้านได้รับแล้ว กำลังดัง รอคนกดรับ |
| ติดค้าง 3 วินาที | หน้าร้านกดรับทราบแล้ว |
| กระพริบถี่แล้วดับ | ส่งไม่ถึง (ตัวหน้าร้านปิดอยู่ หรืออยู่ไกลเกินไป) |

## ปรับแต่ง

- **มีหลายปุ่ม/หลายโต๊ะ:** อัปโหลด `kitchen_button.ino` ลงบอร์ดเพิ่ม แล้วตั้ง `STATION` เป็น 1, 2, 3 … ตัวหน้าร้านรองรับได้ 8 จุด กดรับทราบครั้งเดียวรับทุกจุดที่ค้างอยู่
- **อยากให้ดังกว่านี้:** ให้ GPIO 25 สั่งรีเลย์ไปเปิดกริ่งตัวใหญ่ ถ้ากริ่งใช้ไฟบ้าน 220V ให้ช่างไฟเป็นคนต่อฝั่งนั้น
- **สัญญาณไม่ถึง:** ESP-NOW ไปได้ไกลกว่า Wi-Fi ปกติ แต่ถ้ามีผนังปูนหนาหลายชั้น ลองย้ายบอร์ดให้ห่างจากโลหะ หรือเปลี่ยน `CHANNEL` (1–13) ทั้งสองตัวให้ตรงกัน
- **ระยะเวลาเตือนซ้ำ:** แก้ `REMIND_EVERY` ในไฟล์ `front_bell.ino`
